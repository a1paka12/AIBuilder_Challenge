# 보증금 지킴이 PRD

팀명: [팀명] | 작성일: 2026-10-03 | 배포 URL: https://bojeung.193-123-163-215.sslip.io | 저장소: https://github.com/a1paka12/AIBuilder_Challenge

## 1. 한 줄 소개
**퇴실 공제 통보를 받은 자취 대학생**이 **긴 공제 메시지를 정리하고 무엇을 물어볼지 정하는 귀찮음**을, **AI가 항목·금액을 원문 근거와 함께 표로 정리하고 근거를 묻는 문자를 3분 만에 만들어 주는 방식**으로 해결하는 **퇴실 공제 정리·방 상태 기록 웹 서비스**.

## 2. 문제 정의
- **사용자가 지금 겪는 불편:** 집주인이 "청소비 15만원, 도배 30만원, 장판 25만원… 총 78만원 공제합니다"라고 보내면, 항목·금액을 옮겨 적고, 관련 자료를 찾고, 무엇부터 물을지 정하고, 말을 꺼내는 일이 번거롭고 부담스러워서 그냥 낸다. ("너무 과하다고 생각했지만 싸우기 싫어서 따지지 않고 그냥 전화를 끊었다." — 시사저널 인용 사례)
- **이 문제가 중요한 이유:**
  - 수도권 원룸 대학생 1,006명 중 **12.3%가 이사 때 보증금을 부당하게 차감**당했다고 답했다(2015 대통령직속 청년위원회 조사, 시사저널 2016 보도).
  - 국민대 기숙사 수용률은 **11.2%**(국민대신문, 2017) — 대부분의 학생이 정릉·길음 원룸에 산다. 전국 기숙사 수용률도 22.2%(2025 대학정보공시).
  - 공공 분쟁조정은 집주인이 응하지 않으면 끝난다: 국토부 주택임대차분쟁조정위원회 처리 3,855건 중 **조정 성립 39.3%**, 세입자 신청 각하의 **81.4%가 임대인 불응**(이용선 의원 자료, 2026-09-10 보도).
  - 퇴실 청소비 관행 5~15만원, 도배·장판 교체 요구 수십만~100만원(커뮤니티 사례 15건).

## 3. 타깃 사용자
- **주요 사용자:** 졸업·휴학·입대·교환학생으로 대학가 원룸을 빼는 대학생(우선 국민대 주변).
- **언제, 어디서 쓰나요:** 집주인에게 퇴실 공제 카톡을 받은 직후 휴대폰에서 / 입주·퇴실 날 방 사진을 정리할 때.

## 4. 해결 방법과 차별점
- **핵심 아이디어:** AI는 불규칙한 한국어 메시지를 **읽고 정리**만 한다(항목·청구액·원문 인용, 애매하면 "확인 필요"). 공제가 맞는지 **판단은 하지 않고**, 사용자가 물어볼 항목을 직접 골라 **근거를 묻는 문의 문자**를 만든다.
- **기존 서비스와 다른 점:**
  - 법률 상담 챗봇과 달리 결론("부당하다", "돌려받을 수 있다")을 내지 않는다 → 사용자가 판단하고, 출처·범위가 붙은 공개 자료만 보여 준다.
  - 부동산 플랫폼(직방·다방·집토스)은 계약 전 단계에 집중하고 퇴실 공제 정리는 없다.
  - 방 사진은 서버로 보내지 않고 **파일 지문(SHA-256)만 서버에 기록**해 "이 시각에 이 파일이 있었다"는 기록을 남긴다.

## 5. 핵심 기능 (요구사항)
| ID | 우선순위 | 기능 | 완료 기준 (이렇게 동작하면 성공) |
|----|---------|------|-------------------------------|
| FR-01 | 필수 | 공제 메시지 AI 정리 | 첫 화면 **[예시로 해보기]**를 누르면 예시 메시지가 입력되고 표에 **5개 항목·개별 합계 780,000원**이 나오며 "총 78만원"은 항목이 되지 않는다. **[공제 내역 정리하기]**에서 직접 붙여 넣은 글도 **[정리하기]**를 누르면 실제 AI가 처리해 항목·청구액·원문 인용이 표로 나오고, 단위가 애매한 금액("도배는 30")은 **"확인 필요"**로 표시된다. 빈 입력·3,000자 초과는 AI를 부르지 않고 이유를 안내하고, AI 오류·지연 시 입력은 남은 채 **[다시 시도]**·**[직접 입력]**이 나온다. |
| FR-02 | 필수 | 확인·선택·"내가 근거를 물어볼 금액" | 표의 행마다 **[수정]**·**[확인]**이 있고 금액을 고치면 확인이 풀린다. 확인한 행만 **"물어볼 항목"** 체크가 가능하고, 체크한 항목의 청구액 합계가 **"내가 근거를 물어볼 금액"**으로 즉시 바뀐다(예시: 도배·장판 체크 → **550,000원**). 행 추가·삭제가 된다. |
| FR-03 | 필수 | 참고 자료·특약 표시 | 항목을 누르면 참고 자료 카드(제목·원문 인용·**범위 태그**·출처 링크·확인일)가 나오고, 학생에게 불리한 자료도 함께 나온다. **[특약 문구 붙여넣기]** 칸에 청소·도배·장판·원상복구 등이 있으면 해당 항목에 **"특약 있음 · 상담 필요"**가, 비워 두면 **"특약 확인 안 함"**이 보인다. 화면 어디에도 "부당", "돌려받을 수 있어요" 같은 결론 문구가 없다. |
| FR-04 | 필수 | 문의 문자·다음 단계 | **[문자 만들기]**를 누르면 고정 템플릿 한 종류에 확인·체크한 항목·금액만 들어간 문자가 나오고, **[복사]**를 누르면 "복사했어요"가 뜬다(복사가 안 되면 직접 선택하라는 안내). 체크한 항목이 없으면 문자를 만들지 않고 안내한다. 계약자가 다른 사람이면 "계약자에게 이 내용을 전달해 확인받으세요"가 나온다. **[다음 단계 보기]**에 "키 반납 전에 공제 내역과 금액을 문자로 받아 두세요." 경고, "상담을 고려해 볼 상황" 목록, 무료 기관 4곳과 대한변협 변호사 검색 공식 링크가 보인다. |
| FR-05 | 필수 | 방 상태 기록·기록북 | **[방 상태 기록하기]**에서 구역을 고르고 **[사진 추가]**로 사진을 넣으면(사진은 브라우저 안에서만 사용) 입주/퇴실·메모·날짜(사진 정보상 날짜/직접 입력/미입력)를 적을 수 있고, **[서버 기록 남기기]**를 누르면 **"서버 기록 · 날짜 시각 · 지문 8자리"**가 붙는다. **[기록북 미리보기]**에 표지·구역별 사진·메모·서버 기록이 나오고 **[PDF로 저장]**으로 저장된다. 사진 2장까지 무료 체험이고, 3장째에는 "3장부터는 기록북 상품(4,900원)이에요" 안내와 **[가격 안내]**·**[데모로 계속]**이 나온다. |
| FR-06 | 선택 | 내용증명 빈칸 서식 | 다음 단계의 **[내용증명 서식 만들기]**에서 입력 폼과 실시간 미리보기가 나오고, 확인한 항목·금액이 자동으로 들어간다. **[PDF 받기]**를 누르면 "결제는 아직 연결하지 않았어요. 데모에서는 무료로 받을 수 있어요."와 **[데모로 받기]**가 나오고 저장된다. 압박 문구를 입력하면 "보증금과 관계없는 압박 문구는 넣을 수 없어요."가 뜬다. |
| FR-07 | 선택 | 가격 안내·개인정보 처리방침 | **[가격 안내]**에 무료(공제 정리·참고 자료·문의 문자·다음 단계·기록북 사진 2장)와 유료(기록북 4,900원, 내용증명 서식 PDF 건당, 기관용 — 출시 예정) 표와 "결제는 아직 연결하지 않았어요."가 나온다. 하단 **[개인정보 처리방침]**에 처리 목적·항목·보유·국외 이전(AI 제공사)·보호책임자가 나온다. |

## 6. 사용자 흐름
1. 사용자가 첫 화면에서 **[공제 내역 정리하기]**(또는 **[예시로 해보기]**)를 누른다.
2. 집주인 카톡의 공제 메시지를 붙여 넣고(이름·전화번호·계좌번호는 지우라는 안내) **[정리하기]**를 누른다.
3. AI가 정리한 표에서 금액을 원문과 대조해 **[확인]**하고, 물어볼 항목을 체크한다 → "내가 근거를 물어볼 금액"을 본다.
4. 항목을 눌러 참고 자료(범위 태그 포함)를 읽고, 계약서 특약 문구가 있으면 붙여 넣는다.
5. **[문자 만들기]** → **[복사]**해서 직접 집주인에게 보낸다.
6. **[다음 단계 보기]**에서 키 반납 전 주의, 무료 기관·변호사 검색 링크를 보고, 필요하면 **[내용증명 서식 만들기]**.
7. (별도 흐름) **[방 상태 기록하기]** → 구역별 사진·메모 → **[서버 기록 남기기]** → **[기록북 미리보기]** → **[PDF로 저장]**.

## 7. 화면 구성
- **첫 화면:** 서비스 한 줄 소개, 버튼 4개(**[공제 내역 정리하기] [방 상태 기록하기] [예시로 해보기] [가격 안내]**), 고지 3개(①"보증금 지킴이는 공개 자료를 찾아 보여 주는 정보 제공 도구이며, 법률 판단이나 대리를 하지 않습니다." ②"공제 내역 정리에 생성형 AI를 사용합니다." ③무료/유료 요약), 하단 **[개인정보 처리방침]**.
- **주요 기능 화면:** 공제 정리(입력 → 표 → 참고 자료·특약 → 합계), 방 상태 기록(구역·사진·메모·서버 기록).
- **결과 화면:** 문의 문자(복사), 다음 단계 안내, 내용증명 미리보기, 기록북 미리보기.
- 공통: 로그인 없음. AI가 만든 결과에는 "AI" 배지. 새로고침하면 "체험 데이터는 이 화면에서만 쓰여요" 안내와 함께 처음 상태.

## 8. 기술 구성
- 개발 도구: Claude Code(Claude Opus 5.5), Codex
- 화면(프론트엔드): React 19 + TypeScript + Vite 8 (단일 페이지, 해시 라우팅)
- 서버: Node.js 22 + Express 4 (`server/server.mjs`) — AI 호출과 사진 지문 기록만 담당, API 키는 서버 환경 변수
- 데이터 저장: 공제 메시지·사용자 입력은 **브라우저 메모리에서만** 사용(서버 저장 없음). 서버는 사진 지문 기록(`SHA-256`, 수신 시각, 서명)만 파일에 추가 저장.
- AI 기능: OpenAI API `gpt-5.4-mini`, 구조화 출력(JSON Schema strict) — 항목명·청구액·원문 인용·확인 필요 여부만 받음. 서버가 원문에 없는 인용을 "원문 확인 필요"로 표시하고 개인정보 패턴을 가림.
- 배포: Oracle Cloud 서버(Ubuntu) + Caddy(HTTPS 자동) + systemd

## 9. 비즈니스 모델 · 시장성
- **누가 돈을 내나요 / 수익 모델:**
  - 무료(영구): 공제 정리, 참고 자료, 문의 문자, 다음 단계 안내, 기록북 사진 2장 체험. 어떤 유료 상품과도 묶지 않는다.
  - 유료(가설): **방 상태 기록북 4,900원**(방 1개·이사 1건, 사진 30장·PDF·재다운로드) / **내용증명 빈칸 서식 PDF 건당** / 기관(대학 생활관·지자체)용 기록 관리.
  - 하지 않는 것: 성공보수·해결 수수료, 변호사 소개비, 판단·분석 결과 판매(변호사법 제109조·제34조 위험 회피).
- **시장 규모, 대상 고객 수:** 일반대학 재적생 183.8만 명(2025 교육기본통계) 중 기숙사 밖 거주가 다수(수용률 22.2%). 서울 대학가 원룸 월세 평균 62.5만원(다방, 2026-08). 퇴실은 1년 계약 단위로 반복된다. (연간 퇴실·공제 건수 추정은 가정이 많아 발표에서는 범위로만 말한다.)
- **경쟁 서비스와 우리 강점:** 집토스(입주 체크리스트, 중개 수수료 모델이라 퇴실 분쟁에 약함), 다방·직방(계약 전), HUG 안심전세(전세사기), 법률구조공단 챗봇(일반 정보), 로폼(서식). 우리는 **퇴실 공제 정리 + 근거 문의 + 방 상태 기록**을 한 흐름으로 묶고, 결론을 내지 않는 설계로 법적 위험을 낮췄다.

## 10. 이번에 만들지 않는 것 (범위 밖)
- 실제 결제·환불(가격 안내와 "데모로 계속/받기"만)
- 회원가입·로그인·장기 저장·여러 기기 동기화
- 공제 내역 **사진** 입력과 브라우저 개인정보 가림, 계약서 특약 사진 입력(설계 완료, 다음 단계)
- 변호사 추천·순위 엔진, 상담 예약·사건 자료 자동 전달
- 공제가 적정한지·돌려받을 금액·승소 가능성 판단, 감가 계산
- 문자·카톡 자동 발송, 내용증명 우체국 연계 발송
- 집주인 확인 링크, 문의 진행 상태 관리, 기관용 화면
