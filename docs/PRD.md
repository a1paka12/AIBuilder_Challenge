> 대회: KOOKMIN AI BUILDER CHALLENGE 2026(2026-10-03) · 주제 "귀찮음 주식회사 — 대학 생활의 귀찮은 순간을 돈 받고 해결해 주는 AI 서비스". 이 문서의 5절 완료 기준과 "최종 구현 및 검증" 표가 배포본과 대조하는 기준이다.

## 1. 한 줄 소개

자취 대학생이 보증금 공제 내역과 입주·퇴실 자료를 AI로 정리하고, 문의할 내용과 상담 조건에 맞는 변호사를 찾는 AI 주거 기록 서비스.

## 2. 문제 정의

- 사용자가 지금 겪는 불편: 퇴실 시 청소·도배·장판 비용을 통보받으면 공제 항목과 금액을 옮겨 적고, 사진·계약 내용을 찾아 첫 문의를 작성해야 한다. 상담이 필요하면 변호사의 업무 분야·지역·방식·비용도 직접 비교해야 한다.
- 이 문제가 중요한 이유(근거, 숫자, 경험): 사례 조사에서 입주 사진 부재, 특약 확인, 견적·영수증 부족, 상담 준비가 반복적인 쟁점으로 나타났다. 개인정보가 담긴 자료를 외부 AI에 그대로 전달하는 부담도 있다. 초기에는 공제 항목 5개 확인부터 문의 복사까지 중앙값 3분 이내를 목표로 검증하며, 현재 시간 절감 효과와 구매 수요는 미검증이다.

## 3. 타깃 사용자

- 주요 사용자: 전국 대학가의 원룸·오피스텔 등에 거주하는 자취 대학생. 입주·퇴실을 앞두었거나 공제 내역을 받은 학생, 특히 첫 자취·첫 이사를 경험하는 학생을 우선 대상으로 한다.
- 언제, 어디서 쓰나요: 공제 메시지를 받은 직후, 입주·퇴실 사진을 정리할 때, 상담을 준비할 때 휴대전화 또는 데스크톱 웹에서 사용한다. 입주 사진이나 계약서가 없어도 공제 메시지만으로 정리·문의 기능을 이용한다.

## 4. 해결 방법과 차별점

- 핵심 아이디어: 사용자 기기에서 개인정보를 제거한 뒤 AI가 공제 항목·금액·근거 문장을 추출하고, 사용자가 확인한 항목으로 문의를 준비한다. 상담 조건에 맞는 변호사를 추천하고 입주·퇴실 사진은 기록북으로 정리한다.
- 기존 서비스와 다른 점: 한국어 공제 정리, 기기 내 개인정보 제거, 원문과 금액 확인, 추천 이유가 보이는 변호사 탐색을 연결한다. AI는 공제 책임·특약 효력·환급액을 판단하지 않으며, 문의는 사용자 확인값을 넣는 고정 템플릿으로 제공한다.

### 5-1. 필수 기능의 세부 동작 (채점 대조용)

**FR-01 기기 내 개인정보 제거·전송**

| 구분 | 동작 |
|---|---|
| 텍스트 자동 탐지 | 브라우저(`src/lib/mask.ts`)에서 주민등록번호·휴대전화·일반전화·계좌·이메일 패턴을 찾아 `[전화번호 삭제]` 형식으로 치환. 이름·주소·호수는 사용자가 단어를 추가하면 `[이름 삭제]` 형식으로 치환 |
| 전송본 확인 | "전송본 확인" 패널에 실제 처리본과 가린 항목 수를 표시. [이 전송본으로 정리하기]를 눌러야만 처리본이 `/api/extract`로 전송. 원문을 고치면 확인이 해제되고, 치환에 실패하면 전송이 막힘 |
| 서버로 가는 것 | 처리본 텍스트만. 원문과 치환 대응표는 서버로 가지 않음. 서버(`server.mjs` maskPII)가 2차로 다시 가리고 AI 응답도 재검사 |
| 사진 형식 | JPEG·PNG만 받음. 그 외 형식은 차단하고 안내 |
| 사진 가림 | 사진 위에 불투명 가림 상자를 포인터 드래그 또는 키보드로 추가·이동·크기 조절 → canvas 재인코딩으로 새 파일 생성(EXIF·GPS 등 메타데이터 제거) |
| 사진 전송본 확인 | 가린 처리본을 미리 보고 확인하면, 원본 사진 대신 암호화 해시값만 서버에 기록 |

**FR-03 변호사 조건 추천**

| 구분 | 동작 |
|---|---|
| 진입 | [변호사 찾아보기] → #/lawyer |
| 상담 주제 | 4종 복수 선택: 퇴실 청소·도배 등 원상회복 비용 / 보증금 일부·전액 반환 문의 / 계약서 특약 해석 문의 / 분쟁조정·소액 사건 절차 문의 |
| 조건 | 방식(전화·영상·방문)·지역(방문일 때만)·예산(30분 상담 기준)·희망 시점·언어 — 각각 "꼭 필요 / 선호 / 상관없음" |
| 거르기 | 꼭 필요 조건을 충족하지 않거나 확인되지 않은 후보는 제외. 언어는 꼭 필요일 때만 거름 |
| 조건 일치 점수 | 100 × Σ(활성 기준 가중치 × 일치값) ÷ Σ(활성 기준 가중치)를 반올림한 정수. 가중치 주제 40·방식 20·지역 15·예산 15·시점 10. 주제 일치값 = 확인된 취급 주제 수 ÷ 선택한 주제 수. 상관없음 기준은 제외, 방문을 고르지 않았거나(전화·영상만) 방식·지역을 상관없음으로 두면 지역 제외, 미확인 값은 0점 + "문의 필요". 동점은 확인일 최근 → ID 순 |
| 표시 | 최대 3명 + [전체 후보 보기]. 카드마다 "가상 프로필" 배지, "조건 일치 N", 추천 이유(확인 필드로 만든 고정 문장), 취급 업무와 등록 전문분야 구분, 상담료·시간 또는 "요금 문의 필요", 확인일 |
| 0명 | "현재 조건으로 확인된 후보가 없습니다" + [조건 수정] + 대한변협 공식 변호사 검색 + 공공 무료 상담 경로 |
| 갱신 | 조건을 바꾸면 점수·순위·이유를 즉시 다시 계산(aria-live 알림) |
| 한계·원칙 | 데모용 가상 프로필(실제 변호사 아님, 연락처·예약·후기·승소 실적 없음). 연락·예약·자료 전송 없음. 소개비·수수료·광고비 없고 돈으로 순위가 바뀌지 않음(변호사법 제34조 고려). 공공 무료 상담과 점수를 섞지 않음 |

## 6. 사용자 흐름

1. 사용자가 첫 화면에서 공제 정리·기록북·변호사 찾기 또는 합성 예시 체험을 선택하고, 자료를 입력하는 경우 기기 내 개인정보 제거와 전송본 확인을 완료한다.
2. AI가 정리한 항목·금액을 원문과 대조해 수정·확인하고 물어볼 항목을 선택한 뒤 공개 자료와 합계를 확인하고 문의 문구를 복사한다.
3. 추가 상담이 필요하면 조건에 맞는 변호사 후보나 공공 상담 경로를 선택하고, 사진 기록을 남기려면 별도로 기록북을 편집해 인쇄/PDF로 저장한다.
4. (덧붙임) 첫 방문 시 레이어 팝업(출시 이벤트·혼자 묻기 어렵다면)을 보고 닫거나 #/event·#/help로 이동할 수 있고, 다음 단계에서 #/cert 내용증명 빈칸 서식을 채워 PDF로 저장할 수 있다. 첫 화면 아래 30초 현장 설문과 #/pricing 구매 의향은 결제 없이 응답만 기록한다.
