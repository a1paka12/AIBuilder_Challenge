- 각 시나리오는 **시크릿 창**에서 새로 시작한다(브라우저 메모리 상태가 섞이지 않게).
- "결과" 칸은 실행한 사람이 `통과` / `실패(메모)`로 채운다. 이 문서는 비워 둔 상태로 제출한다.
- 예시 메시지: `퇴실 정산입니다. 청소비 15만원, 도배 전체 30만원, 장판 25만원, 싱크대 시트지 5만원, 샷시 손잡이 3만원입니다. 총 78만원을 공제하려고 합니다.`
